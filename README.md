# ZRF.ME 聚合直播

打开网页就能看虎牙、斗鱼、哔哩、抖音的直播，不用装客户端。

## 域名

四条都指向同一个站点，任选其一：

- https://live.zrfme.com
- https://live.zrfme.net
- https://live.itzrf.com
- https://live.zrfme.de

## 支持

| 平台 | 直播 | 分区 | 搜索 | 弹幕 |
|---|---|---|---|---|
| 虎牙直播 | ✓ | ✓ | ✓ | ✓ |
| 斗鱼直播 | ✓ | ✓ | ✓ | ✓ |
| 哔哩直播 | ✓ | ✓ | ✓ | ✓ |
| 抖音直播 | ✓ | ✓ | — | — |

抖音的搜索要登录态、弹幕要 Cookie，网页里都拿不到，所以只有画面。

关注列表存在浏览器本地，不需要注册账号。
